# 複数テーマ・階層型タスク管理Excel

## 成果物

- `outputs/task_manager/latest/複数テーマ階層型タスク管理_最新版.xlsm`：実運用用マクロ有効ブック
- `vba/`：VBAソース（機能別モジュール）
- `テスト手順書.md`：会社PCでの受入確認手順

## シート構成

| シート | 用途 |
|---|---|
| 01_テーマ一覧 | 複数テーマの状態・マイルストーンの俯瞰 |
| 02_タスク | 1行1タスクのマスター。親子関係はIDで保持 |
| 03_週ガント | L1・L2中心の週単位ガント。`■`から予定日の逆算も可能 |
| 04_日ガント | 全タスクの日単位詳細ガント |
| 05_週次進捗 | タスク×週の文章進捗。既存文章は非破壊で保持 |
| 06_進捗ログ | タスクID×週で正規化した内部ログ |
| 07_課題・リスク | 課題・リスク管理 |
| 08_意思決定 | 判断内容・理由・次アクションの記録 |
| 09_設定 | 階層数、期間、一覧、JSON出力先、進捗開始列など |

## 主なマクロ

- `InitializeWorkbook`：共通書式と操作ボタンを再設定します。
- `RebuildTaskStructure`：L1～L8のうち入力された1セルからLevel・親タスクID・テーマID・タスク名を自動生成し、未採番IDも付与します。
- `AssignTaskIDs`：IDが空の行だけ、Level別の重複しないIDを採番する内部・補助機能です。
- `RefreshThemeList`：L1行からテーマ一覧を自動生成し、テーマ総括だけを保持します。
- `ValidateTaskHierarchy`：親ID、親Level、テーマID、ID重複を検査します。
- `RefreshWeeklyGantt` / `RefreshDailyGantt`：タスクマスターからガントを再生成します。
- `SyncWeeklyGanttToTasks`：週ガントの`■`からタスクの予定開始・終了日を逆算します。

通常予定のガント色は階層別です。L1は濃い青、L2は青、L3は薄い青、L4以降は最も薄い青です。状態が「待ち」の場合はオレンジ、期限超過は赤、完了・中止は灰色となり、階層色より警告・完了色を優先します。設定シートにも同じ凡例があります。
- `RefreshWeeklyProgress`：タスク構造を同期し、既存文章を「タスクID＋週」で復元します。
- `SyncProgressLog`：週次進捗を縦持ちログへ追加・更新します。
- `ExportWorkbookJson` / `ImportWorkbookJson`：IDと列見出し名をキーに、値と主要書式をJSONで移行します。行番号・列番号には依存せず、取込前に自動バックアップします。
- `BackupWorkbook`：設定したフォルダへ時刻付きコピーを保存し、指定世代数を保持します。
- `RefreshAll`：バックアップ後、採番から書式更新までを順番に実行します。

## 初回使用方法

1. `09_設定`で「エクスポートフォルダパス」を会社PC上の書込み可能なフォルダへ変更します。
2. 必要に応じてガント期間、現在週、最大階層数、進捗開始列を変更します。
3. Excel上部の「コンテンツの有効化」でマクロを有効にします。
4. `09_設定`の「全体更新」ボタンを押します。

## 日常運用

1. `02_タスク`へ行を追加し、L1～L8の該当する階層列1つだけに名称と、担当・状態・予定日などを入力します。テーマID、親タスクID、Level、タスク名は入力不要です。
2. 「全体更新」を実行します。既存IDと過去進捗は変更されません。
3. 毎週、`05_週次進捗`の動きがあったタスクだけ記入し、「進捗ログ同期」を実行します。
4. 課題・リスク、意思決定は各専用シートへ追加します。
5. Excel更新版へ移行する前に「JSONエクスポート」を実行し、新版で「JSONインポート」を実行します。

## 非破壊・拡張設計

- L1行をテーマの起点とし、L2以下は直前の上位階層へ自動的に所属します。行順が親→子になるよう並べてください。
- `01_テーマ一覧`はL1行から自動生成されます。責任者・状態・予定日は`02_タスク`のL1行を更新し、テーマ固有の総括だけをテーマ一覧へ記入してください。
- 主要処理は見出し名を検索するため、途中への列追加に強い構成です。見出し名そのものは変更しないでください。
- 最大階層数はL8まで想定しています。L5以上を使う場合は`02_タスク`へ同名列を追加後、設定値を変更して全体更新します。
- 週次進捗はタスクIDと週をキーに退避・復元します。タスクIDを直接書き換えると紐付けできません。
- JSON取込は、テーマID・タスクID・ログID・課題ID・決定ID・設定キーと列見出し名を照合します。行・列が移動していても復元でき、JSONに存在しないセルや新版固有機能は削除しません。
- 週ガントと日ガントはタスクから再生成できるためJSON対象外です。週次進捗はタスクIDと週見出し名で移行します。
- 完了・中止行は全体更新時にグレー化します。
- ガント・進捗更新前の非表示行状態はタスクID単位で保存し、更新後に再現します。

## Windows / Miniconda環境での注意

- 主要ボタンはVBAブリッジからMinicondaのPython処理を非同期で呼び出します。
- 開始時のポップアップは表示しません。処理中はExcelのステータスバーへ表示し、終了時に成功または失敗のポップアップを表示します。
- 失敗時はポップアップに表示される`logs`フォルダ内のログを確認してください。同時に複数のPython処理は実行できません。
- JSONとバックアップの出力先には、会社PCで書込み権限があるローカルまたは社内許可済みフォルダを指定してください。
- 文字化け防止のため、JSONはUTF-8で保存・読込します。
